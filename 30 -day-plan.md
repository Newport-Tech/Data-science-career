# 30- Day Study Plan
### Data Analyst / Junior Data Scientist Foundations

**Goal:** Rebuild strong foundations in Python, SQL, and basic statistics so I can start building real projects confidently

**Daily time commitment:** 1.5 - 2 hours

---

## Week 1: Python Foundations: 
**Focus** Get comfortable with python again

|Day|Topic|
|---|-----|
| 1 | Variables, data types, list, dictionaries |
| 2 | If statements & loops |
| 3 | Functions |
| 4 | Working with files + practice exercises |
| 5 | Introduction to Pandas (reading CSV, basic operations) |
| 6 | Pandas practice (filtering, sorting, basic cleaning)
| 7 | Review + small practice project (analyze a simple dataset) |

---

## Week 2: Pandas + Data Visualization
** Focus:** Become comfortable analyzing data with python

| Day | Topic |
|-----|-------|
|  8  | More Pandas (groupby, merge, missing values)
|  9  | Matplotlib basics |
|  10 | Seaborn basics |
|  11 | Full EDA practice on a real dataset |
|  12 | Data cleaning practice |
|  13 | Mini project: Clean + visualize a dataset|
| 14  | Review Week 1 & 2 |


##  Week 3: SQL Foundations
**Focus:** Learn practical SQL for data analysis
| Day | Topic |
|-----|------|
| 15 | SELECT, WHERE, ORDER BY |
| 16 | Aggregate functions (COUNT, SUM, AVG) + GROUP BY |
| 17 | JOINs (INNER, LEFT) |
| 18 | Practice + practice questions |
| 19 | Window functions (ROW_NUMBER, RANK) |
| 20 | CTEs (WITH statements) |
| 21 | SQL practice problems (mix of easy + medium) |

---

## Week 4: Statistics + Combine Skills
**Focus:** Basic statistics + start thinking like an analyst

| Day | Topic |
|-----|------|
| 22 | Mean, median, mode, variance, standard deviation |
| 23 | Correlation + basic distributions |
| 24 | Intro to hypothesis testing (very simple) |
| 25 | Combine SQL + Python (pull data with SQL ideas, analyze with Pandas) |
| 26 | Mini project: Answer business questions with data |
| 27 | Review everything (Python + SQL + Stats) |
| 28 | Clean up GitHub + update the career README |
| 29 | Review + note weak areas |
| 30 | Light day + plan the first real portfolio project |
